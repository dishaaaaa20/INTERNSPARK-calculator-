# Calculator

A simple interactive calculator built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

## Files
calculator/
├── calc.html
├── stylecalc.css
├── calc.js
└── README.md

## Getting Started

No install needed. Just open `calc.html` in any browser.

```bash
# Or serve it locally with any static server, e.g.
npx serve .
```

## Features

- Basic arithmetic — addition, subtraction, multiplication, division
- Percentage (%) and sign toggle (+/−)
- Expression preview shown above the main display
- Error handling for division by zero
- Chained operations (e.g. 5 + 3 × 2)
- 12-digit display limit with auto scientific notation for large numbers
- Keyboard support

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0–9` | Enter digits |
| `.` | Decimal point |
| `+` `-` `*` `/` | Operators |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last digit |
| `Escape` | Clear (AC) |
| `%` | Percentage |

## Browser Support

Works in all modern browsers — Chrome, Firefox, Safari, Edge.
